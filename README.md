Day-1 Print Function
The print() function is a built-in Python function that displays values or messages to the console. It can print strings, numbers, variables, and expressions, and supports optional parameters like sep (separator) and end (line ending)

print("Hello, World!")

print(100)

name = "Surjeet"
age = 33

print(name)
print(age)

name = "Surjeet"
age = 33

print(name, age)
